# Question board demo

A local page that replays the MD-10 spike as a simulated lecture. Student questions arrive one at a time, the board groups the ones that mean the same thing, and it suggests the slide that answers each. You can also type your own question and see where it lands.

The similarity scores are real bge-m3 (8-bit) output. The sample questions are team-written drafts.

## Run it

```sh
cd spikes/md-10-embeddings
node src/embed.mjs bge-m3-q8     # once: creates out/emb-bge-m3-q8.json
node src/build-demo.mjs          # once: creates demo/index.html
node demo/server.mjs             # then open http://localhost:4173
```

The server loads the model in the background (a few seconds when cached, longer on the first download). The page enables the **Ask** button when the model is ready. Set `PORT` to use another port.

## Run it on a VM

The server listens on 127.0.0.1 only, so reach it through an SSH tunnel from your own computer:

```sh
# on the VM
cd spikes/md-10-embeddings
node src/build-demo.mjs          # rebuild the page from the VM's own vectors
node demo/server.mjs

# on your computer
ssh -L 4173:localhost:4173 <user>@<vm-address>
# then open http://localhost:4173
```

`vm-setup.sh` already creates `out/emb-bge-m3-q8.json` on the VM.

## Ask your own question

Type a question in Thai, English or both, pick one of the examples, or press Enter. The server embeds it on this computer, compares it with the stored question and slide vectors, and returns:

- the top 3 slides with similarity scores, and the slide images
- the similarity to every sample question in the deck, so the board can group it
- the time spent embedding and searching

Your question joins the board after the questions already asked and is grouped with the same rules as the sample questions. Nothing is sent to another machine, and typed questions are not saved to disk.

## Where the slides are

- Slide PDFs: `slides/` in the repo root (not committed, because they are lecturers' material).
- Slide images: `spikes/md-14-pdf-import/out/images/<deck>/NNN.webp` (generated by MD-14, not committed). The page shows them next to each suggested slide when they exist.
- Slide text: `spikes/md-14-pdf-import/data/slides-text.json` (committed).

## Files

- `server.mjs`: serves the page and answers `POST /api/ask`
- `template.html`: the page source
- `index.html`: generated by `src/build-demo.mjs` from the template and `out/emb-bge-m3-q8.json`
