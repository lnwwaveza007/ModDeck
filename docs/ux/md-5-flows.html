      Edge cases

      Activity states

      Live Poll and Word Cloud. State is per session: every new session starts all activities in Draft. Click a state.

      Session

      1. Live: host presses Start session, PIN assigned.
      2. Host away: host connection lost. Students keep answering. Co-host can take over after 2 min.
      3. Ended: host held End for 2 s, or nobody controlled it for 30 min.
      4. Undo: within 60 s of ending, the owner can reopen with the same PIN.
      5. PIN kept 24 h after the end, then free.

      Q&A board

      • Open: students ask and upvote.
      • Paused: list visible, no new questions.
      • Off: tab shows "Q&A is off".
      • Archived: session ended, read-only.

      One question

      • Visible → Highlighted (on projector, one at a time)
      • Answered: tag shown, still upvotable
      • Hidden: host hid it, author still sees it
      • Merged: duplicate, upvotes move to the original
      • Deleted: author removed it
